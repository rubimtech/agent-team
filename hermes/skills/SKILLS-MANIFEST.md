# Скиллы команды: откуда берутся и как отбираются

Скиллы — «процедурная память» ботов. Команда читает их из **одного общего каталога**:
`<HERMES_HOME>/skills-revita` (указывается каждому профилю в `skills.external_dirs`).
Копировать 70+ скиллов в каждый профиль не нужно — это умножает индекс и место на диске.

## Два источника

| Источник | Что это | Откуда берётся |
|---|---|---|
| **Репозиторные** | 103 скилла `.kilo/skills/` — Revit API, паттерны Nice3point, multi-version, MCP-тулы, WPF/UI, тестирование, инженерные расчёты | едет вместе с репозиторием: `{{REPO}}/.kilo/skills` |
| **Hermes-native** | 10 скиллов, которых в репозитории нет (написаны под Hermes-обвязку) | копируются в `skills/hermes-native/` этого каталога |

### Hermes-native (копируются из экспорта)

| Скилл | Зачем команде |
|---|---|
| `revit-mcp-tool-operations` | работа с Revit через MCP: discovery-лестница, конверт ответа, read-back, провенанс деплоя, стенд-полигон |
| `revit-reuse-ladder` | лестница переиспользования перед написанием нового кода |
| `revit-ai-agent-console` | внутренняя агентская консоль репозитория (`apps/agent-console`) |
| `qdrant-kb-and-cgc-mcp` | как искать по Qdrant-коллекциям Revit API и по графу кода; калибровочный гейт |
| `task-manager`, `task-manager-insights` | очередь задач команды (MCP + REST) |

## Правило отбора (почему не копируется всё подряд)

Перед копированием скилл сверяется по **frontmatter `name:`** с уже установленными скиллами
Hermes. Совпадение = дубль: два скилла с одинаковым триггером делают выбор недетерминированным,
а описания обоих платятся в системном промпте каждый ход. `apply_team.py` делает эту сверку
автоматически и печатает, сколько пропущено как дубли.

Дополнительно при копировании срезается «упаковка чужого харнесса» — вложенные каталоги
`skills/`, `agents/`, `commands/`, `.claude-plugin/`: Hermes их не читает.

## Что важно в формате скилла

- Frontmatter с `---` с первой строки файла, поля `name` и `description`.
- **`description` ≤ 60 символов** — Hermes обрезает длинное описание в индексе системного
  промпта, и триггер теряется. Формула: `Use when <триггер>. <поведение>.`
- Скилл без frontmatter для индекса невидим.

## Обновление каталога

```bash
# пересобрать экспорт из текущего состояния профилей и скиллов
python agent-team/scripts/export_team.py

# переустановить скиллы на машине (идемпотентно; дубли пропускаются)
python agent-team/scripts/apply_team.py --apply
```
