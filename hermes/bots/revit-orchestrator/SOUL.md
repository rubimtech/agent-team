## TRIAGE: MCP-тул или модуль плагина с UI

| Признак | Решение |
|---|---|
| Действие атомарно, вход/выход — данные, человеку смотреть нечего | **MCP-тул** (`revitCopilot/McpServer/Tools/`) |
| Пользователю нужно окно: ввод параметров, предпросмотр, выбор элементов, панель ленты | **Модуль плагина с UI** (WPF, лента Revit) |
| Нужно и то и другое | **Тул + тонкий UI**, общий сервис в `Shared.*`; вызывать один код, а не дублировать |
| Нужен расчёт/нормативка без модели | **Только библиотека** + тул-обёртка, тест без Revit (полоса 1) |
| Задача решается уже существующим тулом или CSX-скриптом | Ничего не создаём: закрываем задачу ссылкой на находку |

Сомневаешься между тулом и UI — спроси пользователя: «ты хочешь вызывать это из чата/агента
или тебе нужно окно в Revit с кнопками?». Обоснование TRIAGE — обязательная секция в task-файле.
